# the-manual-is-markdown

The manual lives at
`home/dot_config/nushell/help/manual/` and is deployed by `chezmoi apply`
like the rest of the configuration. Three directories:

- `guide/` and `reference/` — generated by `scripts/generate-manual.mjs`
  (`just manual`) from the four `.nuon` surfaces in
  `home/dot_config/nushell/help/`. These cannot drift from the
  surfaces; regenerate after every `.nuon` edit.
- `internals/` — hand-written. A new page gets its index row in
  `internals/index.md` in the same change. Nothing regenerates it.

Two entry points:

- `?` (or `docs`) — television over every line of every page. Type a
  phrase, Enter opens the file in nvim at that line. The line-by-line
  picker is what makes the manual worth reading; a manual that has to be
  built and served before you can search it does not get read.
- `help <name>` — over the entries the `.nuon` surfaces carry. Four
  surfaces: `capsule.nuon`, `nvim.nuon`, `shell.nuon`, `terminal.nuon`.

**There is no docs site to serve.** The 2026-08-31 fumadocs site was
built and deleted the same day; the markdown is the manual, the picker
is the search. See `decision/the-manual-is-markdown`.
