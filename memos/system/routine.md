# routine

A procedure: steps that plug memos, recipes and commands together into one
run — read, pick, do, check, close. Frontmatter carries `name:`, the
invocation handle. Trust: followed literally or not at all, and a step that
drifted from reality is fixed in the same change. Exempt from the one-claim
rule, a procedure being a list by nature.

Its value is the ingredient block, not the steps: step 1 names every memo,
recipe and command the run opens, by leaf name and literal path, so the
author's search happens once at write time and every later run inherits it.
A routine that names no ingredient is a style guide.
