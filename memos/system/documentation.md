# documentation

How to use or operate: a reference, an index, the protocol itself. Trust:
it must match reality — a row whose file is gone is a bug, a command that
no longer runs is a bug. Exempt from the one-claim rule: an index and a
reference are lists by nature, so its body may carry its own `## ` headings.
