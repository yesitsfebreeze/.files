## How to read this

**Manual** answers *what do I press*. It is generated from the same four
`.nuon` surface files that `help` reads in the shell, so the site and the
shell manual cannot disagree — one set of entries, two renderers.

**Internals** answers *why is the config written that way*. These are the
constraints that cost a day each to find: a terminfo entry that is absent on
minimal hosts, a tmux format delimiter that must not be a glob metacharacter,
an option assignment that silently suppresses an OSC 52.

Use the search (`⌘K`) — it indexes both.
