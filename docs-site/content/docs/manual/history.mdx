## `Ctrl-R`

**Search this directory's history**

*Shell*

Press `Ctrl-R`: a picker opens over the commands you have run *in this directory*, newest first and deduplicated, prefilled with whatever you had typed up to the cursor. Enter replaces the command line with the pick; Esc leaves the line alone.

<Callout title="Why it is this way">
Directory-scoped is the default because a command worth repeating is nearly always one you ran here; the global list is one modifier away. The sqlite store runs with `isolation: false` so every pane contributes to one merged history.
</Callout>

See also: [`Alt-R`](/docs/manual/history#alt-r) · [`Up / Down`](/docs/manual/history#up-down)

## `Alt-R`

**Search the whole history, from anywhere**

*Shell*

Press `Alt-R` for television's own shell-history picker over every command from every directory. Enter puts the pick on the command line.

<Callout title="Why it is this way">
`Alt`, not `Ctrl-Shift`. The kitty keyboard protocol stays off — it leaks `^[[?0u` through the WezTerm pty — and without it shift is indistinguishable on a control+letter chord, so `Ctrl-Shift-R` would arrive as plain `Ctrl-R` and shadow the local picker.
</Callout>

See also: [`Ctrl-R`](/docs/manual/history#ctrl-r) · [`Shift+Up / Shift+Down`](/docs/manual/history#shift-up-shift-down)  
Spec: `prds/04-shell/05-history/prd.md`

## `Up / Down`

**Step through this directory's history on the line**

*Shell*

With the cursor on the command line, `Up` walks back through this directory's commands and `Down` forward; typing anything resets you to the newest. No picker, no screen change.

<Callout title="Why it is this way">
Both keys try `menuup`/`menudown` first in an `until` chain, so with a completion menu open the arrows still navigate the menu. And these bindings are appended *after* television's generated init, because reedline resolves last-entry-wins and tv's own Ctrl-R would otherwise take the key.
</Callout>

See also: [`Shift+Up / Shift+Down`](/docs/manual/history#shift-up-shift-down) · [`Ctrl-R`](/docs/manual/history#ctrl-r)  
Spec: `prds/04-shell/05-history/prd.md`

## `Shift+Up / Shift+Down`

**Step through the whole history on the line**

*Shell*

Hold shift with the arrows for reedline's own global traversal — the same inline stepping, ignoring which directory you are in. Use it when the command you want was run somewhere else.

See also: [`Up / Down`](/docs/manual/history#up-down) · [`Alt-R`](/docs/manual/history#alt-r)
