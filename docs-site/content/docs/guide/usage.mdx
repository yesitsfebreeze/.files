Nushell is the shell, tmux owns the windows, Neovim is the editor and WezTerm only draws the picture. Everything below is reachable from a fresh terminal with no setup. If you learn nothing else: type a directory name on its own to jump to it, `F5` and a digit to change window, `Ctrl-Space` to find anything, and `help` to get back here.
