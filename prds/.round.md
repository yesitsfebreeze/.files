## Decided
- **A malformed box is a fourth kind, and is rewritten rather than ticked or
  left open.** `bash gates/selftest.sh still exits 0` was a **delta** claim
  ("still") written as an **absolute**, presupposing a baseline that never
  existed, and whole-workspace, which the spec template forbids. Rewritten to
  what it meant — *the FAIL set is unchanged by this script's presence* — and
  ticked against the both-ways measurement.
- **A worker's refusal can be right while the footprint is wrong.** The
  `06-nvim-session` implementer would not touch `tests/nvim-small-plugins.sh`
  (out of footprint) and specified the repair instead. Correct — but that file
  is the exact analogue of `tests/nvim-options.sh`, whose census the analyst
  DID update and DID list. One census file was listed and its sibling was not.
  Orchestrator widened the footprint and made the repair.
- **A census inside an invariant decays like a measurement.** Memo
  [`an-invariant-naming-a-defect-must-be-re-measured`](memos/an-invariant-naming-a-defect-must-be-re-measured-before-a-child-inherits-it.md);
  `06-help` I5's four-target claim measured 0/7/59 and was amended.
- **The two capsule keys get a named constraint, not a `needs:` edge** —
  `04-recent-workspaces` is already `done`, so an edge would gate nothing.
  `tests/capsule-recents.sh --keys` is the real enforcement.
