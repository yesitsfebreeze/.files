# Nvim.txt — the editor

Last updated: 2026-11-04

~/.config/nvim/. lazy.nvim bootstrap (config/lazy.lua); plugin specs in
lua/plugins/; options, keymaps, autocmds in lua/config/. Deep detail:
manual internals/neovim.md (searchable with `?`).

Plugins (lazy-lock.json pins): which-key, telescope (the editor's picker —
two finders deliberately: television in the shell, telescope in the
editor), gitsigns, completion, conform, lsp, treesitter, explorer,
statusline, autopairs, table-mode, session, colorscheme (base16 via
tinty's palette), shift-select, claude.

Files open in Insert: a `BufWinEnter` autocmd runs `startinsert`, since
Neovim removed Vim's `'insertmode'` easy mode. `Esc` returns to Insert,
closing a focused picker, float or the leader first. `F6` opens the leader
in Normal at once; a second `F6` closes it and stays in Normal. Neither
gesture waits for a possible second key.

Only plain editable files get Insert. One rule in `lua/config/insert.lua`
decides it for every path (opening a buffer, `Esc`, closing the leader):
buffers with a `buftype` (oil, :Lazy, :Mason, help, quickfix, checkhealth,
terminal, plugin floats), unmodifiable or readonly buffers and plugin URIs
such as `oil://` or `fugitive://` stay in Normal. A screen like that which
takes focus while Insert is on leaves Insert; prompt buffers (telescope)
keep it. The check runs one tick after `BufWinEnter`, because oil sets its
`buftype` only after that event.

Telescope find_files and live_grep cycle normal → hidden files →
gitignored files on <C-.>, the same modes television cycles in the shell
pickers (terminal.txt); the prompt title names the mode, and one mode
index is shared between both pickers.

Hard-won constraints worth carrying into any change:

- the cursor is a block in every mode and keeps its cell across Insert and
  Normal: Insert leaves with `<C-\><C-n>` and restores its column, because
  Esc would move the block one cell left. Insert draws the foreground
  color on the background color; Normal keeps the blue that Insert carries
  in the statusline; Visual, Replace and Command take the background of
  lualine's `lualine_a_<mode>` group. Shape and colors live in
  colorscheme.lua.
- lualine's `auto` theme breaks on base16 — the statusline pins the theme.
- an unrotated LSP log can hit double-digit GB — it is rotated.
- a `dofile` must never become a `require`: module-name caching hands
  back the first read on a second call.
- The icon set in the shell's `ls` overlay is machine-copied from
  nvim-web-devicons (lazy-lock pin) — never hand-typed, so shell and
  editor never disagree.
- mason registry seeding happens as a deploy hook (seed-mason-registry.sh).

No cursor animation (2026-10-12): smear-cursor.nvim and the config/smear-tmux.lua
metadata bridge were removed. Neovim draws the plain terminal cursor; any cursor
trail is tmux's `cursor-smear` option alone, and that is off by default.
